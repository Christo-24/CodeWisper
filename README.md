# Jarvis_Leetcode

Minimal full-stack project for capturing audio, transcribing via a local Whisper service, and uploading screenshots for OCR + assistant hints.

**Structure**
- `backend/`: Django project. Key paths:
  - `mentor/services/whisper_service.py` - runs transcription using `faster_whisper`.
  - `mentor/api/views.py` - API endpoints used by the frontend.
- `frontend/`: Vite + React app. Key paths:
  - `src/components/voiceRecoder.jsx` - simple Start/Stop recorder that POSTs audio to the backend.
  - `src/services/api.js` - helper for `upload_frame` endpoint.

**Backend**
- Install dependencies and run (from `backend/`):

```
python -m venv .venv
.
\.venv\Scripts\activate
pip install -r requirements.txt
python manage.py runserver
```

- API endpoints
  - `POST /api/transcribe/` - accepts multipart form with file field `audio` (the frontend sends a `recording.webm` blob). Returns JSON: `{ "text": "..." }`.
  - `POST /api/upload_frame/` - accepts JSON `{ image: "data:image/...base64..." }` and returns extracted `problem`, `code`, and a `hint`.

**Frontend**
- Install and run (from `frontend/`):

```
npm install
npm run dev
```

- Notes
  - `voiceRecoder.jsx` uses the browser `MediaRecorder` API and posts a `webm` blob to `http://localhost:8000/api/transcribe/`.
  - The browser must allow microphone access. The recorder is intentionally minimal: two buttons (Start Recording / Stop Recording) and a transcript display.

**How it works (high level)**
- Frontend records audio → posts as `FormData` `audio` → Django `mentor.api.views.transcribe` writes temporary `.webm` file → `mentor.services.whisper_service.transcribe_audio` runs `faster_whisper` model → response JSON with `text`.

**Troubleshooting**
- If audio upload fails, confirm backend is running at `http://localhost:8000` and CORS / network settings allow the request.
- If transcription text is empty, check `backend/mentor/services/whisper_service.py` and that the model files are available and the server has access to GPU (or change device settings).
